## قانون اصلی این پروژه

> **درسی که محتوا ندارد، وجود ندارد.**

نسخهٔ قبلی ۳۴۲ درس اعلام می‌کرد که **۲۰۰ تای آن هیچ محتوایی نداشت**؛ موتور بازی از روی
عنوان درس محتوای ساختگی می‌ساخت و به همین دلیل هر ۱۱ اسکریپت ممیزی سبز می‌ماندند.

حالا `scripts/validate.js` هر درس توخالی را مردود می‌کند. عددی که این پروژه اعلام می‌کند،
عددِ واقعی است.

| | نسخهٔ ۳.۳.۳ | نسخهٔ ۴.۰ |
|---|---|---|
| درس‌های اعلام‌شده | ۳۴۲ | **۲۳** |
| درس‌های دارای محتوای واقعی | ۱۴۲ | **۲۳** |
| درس‌های توخالی | **۲۰۰** | **۰** |
| ردهٔ سنی واقعاً متفاوت | ✗ (هر ۱۴۲ درس یکسان) | ✓ (۲/۳/۴ گزینه) |
| حجم مخزن | ۱۲۰ MB | **~۳ MB** |

## محتوا از کجا می‌آید

**ترتیب آموزش حروف** از فهرست درس‌های کتاب فارسی اول دبستان گرفته شده، نه از ترتیب الفبا.
دلیلش عملی است: با ترتیب مدرسه، کودک بعد از سه درس («ا ب / اَ د / م س») می‌تواند «ماست»
و «سام» را بخواند؛ با ترتیب الفبایی بعد از سه درس فقط «ا ب پ ت» را می‌داند و هیچ کلمه‌ای
نمی‌تواند بسازد. جزئیات در `src/data/neshaneh.js`.

**قانون کلمهٔ خواندنی:** هیچ کلمه‌ای — حتی به‌عنوان گزینهٔ نادرست — نشان داده نمی‌شود اگر
حرفی داشته باشد که هنوز آموزش داده نشده. این قانون مکانیکی بررسی می‌شود؛ آخرین اندازه‌گیری:
**۷٬۸۰۰ گزینه، صفر نشت**.

**پیشرفت ریاضی** بر پایهٔ توالی پژوهشی مهارت‌های عددی چیده شده: شمردن با تناظر یک‌به‌یک →
درک کاردینالیتی → مقایسهٔ مقدار → جمع و تفریق.

## بازی‌ها

| بازی | مهارت |
|------|-------|
| صدای حرف | تشخیص شنیداری، با کلیپ ضبط‌شده |

| کلمه با این حرف | ترکیب حرف و کلمه (فقط کلمات خواندنی) |
| شمردن (ردیفی و پراکنده) | تناظر یک‌به‌یک؛ چیدمان پراکنده سخت‌تر است |
| کم و زیاد | مقایسهٔ مقدار |
| جمع و تفریق | عملیات پایه |
| الگوی رنگ و شکل | الگویابی |
| کدام فرق دارد؟ | دسته‌بندی معنایی + دلیل |
| مرتب کردن | ترتیب اندازه و عدد |
| بازی حافظه | حافظهٔ کاری دیداری |
| **کدام شکلِ رنگی؟** | توجه انتخابی (شکل + رنگ هم‌زمان) |
| **کدام حیوان/میوه است؟** | دسته‌بندی با تصویر |
| **سایهٔ کدام است؟** | ادراک دیداری |

## صدا

**۷۹ کلیپ صدای کودکانهٔ فارسی** — تنها بخشی که از نسخهٔ قبلی حفظ شد، چون تنها بخشی بود
که ۱۰۰٪ سالم بود (۷۹ از ۷۹ به فایل واقعی می‌رسیدند).

> ⚠ **هرگز از Text-to-Speech استفاده نکنید.** WebView اندروید صدای فارسی ندارد؛
> نتیجه یا سکوت است یا تلفظ غلط با لهجهٔ بزرگسال. هر خط گفتاری باید کلیپ ضبط‌شده داشته باشد.

برای افزودن خط گفتاری جدید: فایل mp3 را در `assets/audio/kid/` بگذارید و
`node scripts/sync-narration.js` را اجرا کنید. اعتبارسنج مطمئن می‌شود هیچ خطی بدون فایل نماند.

## افزودن درس

۱. درس را در `src/data/lessons/<حوزه>.js` بنویسید — با `goal`، `parentNote` و `rounds` واقعی.
۲. نوع هر گِرد باید در `SUPPORTED_ROUND_KINDS` باشد، وگرنه اعتبارسنج شکست می‌خورد.
۳. `npm test` را اجرا کنید.

هیچ درسی را بدون گِرد اضافه نکنید — این دقیقاً همان اشتباهی است که نسخهٔ قبلی را از بین برد.

## حریم خصوصی

هیچ داده‌ای جمع‌آوری یا ارسال نمی‌شود. همه‌چیز در `localStorage` همان دستگاه می‌ماند.
برنامه به اینترنت نیاز ندارد.
