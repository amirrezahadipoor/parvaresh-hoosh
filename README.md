# پرورش هوش کودک

اپلیکیشن آموزشی و بازی تعاملی فارسی، راست‌به‌چپ و آفلاین برای تمرین مهارت‌های کودکان **۴ تا ۸ سال**.

> این برنامه ابزار آموزش و تمرین است؛ آزمون IQ، تشخیص پزشکی/روان‌شناختی یا جایگزین ارزیابی متخصص نیست.

## وضعیت نسخهٔ ۳.۲.۰

- **۳۴۲ درس پیاده‌سازی‌شده** با شناسهٔ یکتا
- **۷ حوزهٔ آموزشی** و ۷۲ سطح
- ۱۰۶ نوع مهارت و ۱۲ موتور/قالب فعالیت
- ۷ بازی آزاد در شهربازی
- ۵ شخصیت همراه
- ۱۰۹۵ کلیپ گفتار فارسی ازپیش‌تولیدشده
- PWA و بسته‌بندی Android با Capacitor
- ذخیره‌سازی محلی، گزارش والد و پشتیبان‌گیری آفلاین

«پیاده‌سازی‌شده» یعنی هر درس به برنامهٔ تولید فعالیت متصل است و quality gate ساختاری را می‌گذراند؛ این واژه به معنی تأیید بالینی یا بازبینی همهٔ درس‌ها توسط متخصص مستقل نیست.

## فعالیت‌ها

کوییز، حافظه، کشیدن و تطبیق، مرتب‌سازی مراحل، ردگیری حروف و اعداد، نقاشی، بادکنک، ماتریس تصویری، تطبیق سایه، حافظهٔ توالی، تشخیص آیتم ناپدیدشده و ترازوی مقایسه‌ای.

## صدا و حریم خصوصی

اپ در زمان اجرا از Web Speech یا سرویس TTS استفاده نمی‌کند. گفتارها فایل‌های MP3 محلی‌اند که در مرحلهٔ تولید با صدای عصبی فارسی و پردازش pitch/formant ساخته شده‌اند. اپ برای اجرای اصلی به API یا سرور خارجی درخواست نمی‌فرستد. پیشرفت و تنظیمات در IndexedDB/LocalStorage دستگاه ذخیره می‌شوند.

فایل پشتیبان JSON رمزگذاری‌شده نیست و باید مانند اطلاعات خصوصی کودک نگهداری شود. جزئیات در [حریم خصوصی](privacy.html) و [شرایط استفاده](terms.html) آمده است.

## پیش‌نیاز توسعه

- Node.js 24 یا جدیدتر
- npm
- برای Android: Java 21 و Android SDK

## اجرا

```bash
npm ci
npm test
npm start
```

سپس `http://localhost:8080` را باز کنید.

## همگام‌سازی محتوا

`content/curriculum.json` منبع اصلی curriculum است. پس از ویرایش آن:

```bash
npm run sync:content
npm test
```

این فرمان fallback جاوااسکریپت و manifest را بازتولید می‌کند. CI هرگونه اختلاف نسخه، تعداد، عنوان، status یا metadata را رد می‌کند.

## ساخت

```bash
npm run build:web
npm run android:sync
npm run android:debug
```

خروجی وب در `www/` ساخته می‌شود و در Git نگهداری نمی‌شود. Release رسمی باید فقط با tag معنایی (`v3.2.0`) یا اجرای دستی workflow ساخته شود؛ push عادی فقط تست و build را اجرا می‌کند.

## تست‌ها و quality gates

`npm test` این موارد را بررسی می‌کند:

- یکسان بودن نسخه و metadata در package، Android، curriculum، manifest و fallback
- یکتایی شناسه و عنوان و کامل بودن فیلدهای درس‌ها
- mapping و تعداد round تمام ۳۴۲ درس
- دارایی‌های SVG و icon
- ممنوع بودن TTS در runtime و وجود ۱۰۹۵ فایل گفتار
- ۳۵٬۰۰۰ نمونهٔ age-rule و پاسخ‌پذیری فعالیت‌ها
- ۶۹٬۶۸۰ نمونهٔ semantic برای درستی گزینه‌ها، حروف، محاسبات، ساعت، matching و ordering
- ممنوعیت محتوای cross-domain در ورود مستقیم به هر موضوع
- تطابق یک‌به‌یک ۱۰۰۸ متن runtime با فایل صوتی و ledger ‏SHA-256
- syntax همهٔ فایل‌های JavaScript
- render ساختاری همهٔ componentها و smoke test در JSDOM

CI علاوه بر این موارد، Chromium واقعی را نصب می‌کند و `npm run test:e2e` را برای startup، RTL، onboarding، هفت حوزه، هفت بازی، اجرای درس، نام دسترس‌پذیر کنترل‌ها و cold reload کاملاً آفلاین اجرا می‌کند. برای اجرای محلی ابتدا `npx playwright-core install --with-deps chromium` را اجرا کنید.

تست Chromium هنوز جای TalkBack یا دستگاه Android واقعی را نمی‌گیرد. checklist انتشار در [`docs/RELEASE_CHECKLIST_FA.md`](docs/RELEASE_CHECKLIST_FA.md) ثبت شده است.

## ساختار

- `content/`: curriculum و manifest
- `src/activities/`: موتورهای فعالیت
- `src/core/`: ذخیره‌سازی، صدا، تطبیق، گزارش و ناوبری
- `src/data/`: داده و fallbackهای آفلاین
- `scripts/`: همگام‌سازی، audit و build
- `android/`: پوستهٔ Capacitor Android
