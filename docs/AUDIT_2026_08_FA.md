## ۲. یافتهٔ ریشه‌ای: تولیدکنندهٔ محتوا، نبودِ محتوا را پنهان می‌کند

در `src/activities/generator.js` خط ۲۴۵۹:

```js
function lessonPlan(lessonId, metadata) {
    const pkg = window.LESSON_PACKAGES && window.LESSON_PACKAGES[lessonId];
    {
        const lvl = lessonLevel(lessonId, metadata);
        const tp = titlePlan(metadata, lvl);
        if (tp) return plan(tp, { ...metadata, difficulty: lvl });   // ← پیش از دیدنِ pkg برمی‌گردد
    }
    ...
```

`pkg` (محتوای تألیف‌شده) خوانده می‌شود اما **بلافاصله `titlePlan()` که فقط عنوان درس را regex می‌کند، زودتر خروجی می‌دهد**. یعنی:

- درسی که محتوای واقعی دارد، ممکن است محتوایش نادیده گرفته شود.
- درسی که هیچ محتوایی ندارد، از روی چند کلمهٔ عنوانش یک بازی سرِ هم می‌شود.

در هر دو حالت خروجی «یک صفحهٔ کارکننده» است، پس هیچ تستی شکایت نمی‌کند. این دقیقاً همان چیزی است که باعث شده پروژه هم‌زمان «کامل» و «توخالی» باشد.

### محتوا هم واقعاً تألیف‌شده نیست

از ۱۴۲ بستهٔ موجود:

| میدان | مقدار یکتا | از |
|-------|-----------|-----|
| `mistakeFeedback` | **۱** | ۱۴۲ |
| `example` (بدون برچسب) | **۱** | ۱۴۲ |
| `ageTracks` | **۱** | ۱۴۲ |
| `story` (بدون عنوان) | **۶** | ۱۴۲ |
| `objective` | ۶۵ | ۱۴۲ |

یعنی «داستان» هر درس، یکی از ۶ الگوی ثابت است که عنوان درس داخلش چسبانده شده:

> «دانا امروز در جزیرهٔ واژه‌ها به یک مأموریت کوچک می‌رود: «‌{عنوان}‌».»

و مهم‌تر: **`ageTracks` در هر ۱۴۲ درس بایت‌به‌بایت یکسان است.** پس «تطبیق با سن» که ستون فقراتِ ادعای محصول است، در عمل وجود ندارد — فقط یک شیء تکراری است.

## ۷. جهت‌گیری بازسازی

سه اصل که مستقیماً از یافته‌های بالا می‌آیند:

**۱. محتوا داده است، نه کد.** درس‌ها باید در فایل‌های داده‌ای تألیف شوند و اعتبارسنج، درسِ بدون محتوا را **مردود** کند — نه اینکه موتور برنامه جایش را با چیز ساختگی پر کند. اگر درسی محتوا ندارد، باید در برنامهٔ درسی «تألیف‌نشده» علامت بخورد و در برنامه نمایش داده نشود. عدد صادقانه بهتر از ۱۰۰٪ دروغین است.

**۲. یک منبع حقیقت.** بازهٔ سنی، فهرست درس‌ها و نگاشت صدا هرکدام باید دقیقاً یک جا تعریف شوند و بقیه از آن مشتق شوند.

**۳. اعتبارسنجی باید بتواند شکست بخورد.** یک اعتبارسنج که واقعاً قرمز می‌شود، از ۱۱ ممیزی که همیشه سبزند ارزشمندتر است.
