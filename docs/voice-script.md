# موجودی و قرارداد گفتار نسخهٔ ۳.۳.۲

برنامه در زمان اجرا از TTS یا Web Speech استفاده نمی‌کند. تمام گفتار از فایل‌های
`assets/audio/kid/*.mp3` پخش می‌شود.

## آمار قابل بازتولید

- فایل MP3 فعال: **۱۱۰۳**
- حرف فارسی: **۳۲ از ۳۲**
- duplicate باینری دقیق: **صفر**
- نگاشت متن به کلیپ: از `src/data/narration-map.js`
- manifest خطوط تولید خودکار: `assets/audio/kid/auto-manifest.json`
- ledger متن/هش تمام فایل‌ها: `assets/audio/kid/narration-provenance.json`
- متن runtime یکتا: **۱۰۱۶**؛ اشتراک یک فایل بین چند جمله: **صفر**

برای بازتولید wiring پس از تغییر فایل‌ها:

```bash
node scripts/sync_narration.js
npm run audit:voice
```

این فرمان سه منبع را همگام می‌کند: نگاشت متن، guard کلیپ‌ها در `audio.js` و
فهرست offline service worker.

## منشأ صدا

کلیپ‌ها با صدای عصبی فارسی `fa-IR-DilaraNeural` در مرحلهٔ توسعه تولید شده‌اند.
بخشی از pipeline با pitch برابر ۱٫۲۸ و formant shifting به timbre کودک نزدیک
می‌شود. بنابراین عبارت دقیق محصول «گفتار فارسی ازپیش‌تولیدشده و پردازش‌شده» است،
نه «صدای ضبط‌شدهٔ کودک» و نه «TTS زمان اجرا».

## بازبینی انتشار

پیش از انتشار رسمی، نمونه‌های حروف، اعداد، دستورها و تحسین‌ها باید با هدفون و
بلندگوی حداقل دو دستگاه توسط فارسی‌زبان و متخصص آموزش کودک شنیده شوند. نتیجه،
نام بازبین، تاریخ و موارد اصلاح‌شده در release checklist ثبت می‌شود.

## اصلاح تلفظ ث و ف (۲۰ اوت ۲۰۲۶)

دو فایل زیر از نو تولید شدند تا صدای حروف با هم اشتباه شنیده نشود:

- `letter-se.mp3`: «این حرف ث است؛ ثِ سه‌نقطه. در فارسی صدای س می‌دهد. کلمهٔ ثانیه با حرف ث شروع می‌شود.»
- `letter-fe.mp3`: «این حرف ف است؛ فِ تک‌نقطه. صدای ف می‌دهد. کلمهٔ فیل با حرف ف شروع می‌شود.»

متن «سه‌نقطه/تک‌نقطه» عمداً به گویندگی اضافه شده است. فایل‌های اصلاحی mono،
۲۴ کیلوهرتز و مستقل از TTS زمان اجرا هستند.

## ممیزی تلفظ فارسی نسخهٔ ۳.۳.۲

- تمام transcriptها با Unicode NFC و حروف فارسی «ی/ک» نگهداری می‌شوند.
- رقم لاتین، نویسهٔ جایگزین، کشیده و عبارت‌های محاوره‌ای مبهم در گفتار ممنوع‌اند.
- عبارت‌های «چی غذا بدیم»، «بذار» و «هر چی» به فارسی رسمی تبدیل شدند.
- نام‌های حیوانات از لقب‌های مبهم مانند «هاپو/پیشی» به سگ/گربه تبدیل شدند.
- برای حروف هم‌آوا، نام نویسه و واج فارسی جداگانه گفته می‌شود:
  ث→س، ح→ه، ذ→ز، ص→س، ض→ز، ط→ت و ظ→ز.
- «ه» با عبارت «هِ دوچشم» و «ث» با «ثِ سه‌نقطه» از نویسه‌های مشابه متمایز می‌شوند.
